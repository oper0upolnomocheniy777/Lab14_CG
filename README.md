# Освещение сцены

## 🎯 Цели проекта
Реализация системы освещения сцены с поддержкой:
- Трех типов источников света
- Трех моделей освещения материалов
- Загрузки сложных сцен из файлов

## 📦 Основные требования

### Сцена
- Минимум 5 различных объектов
- Осмысленная композиция объектов
- Все объекты имеют текстуры
- Загрузка объектов и нормалей из файлов

### Источники света (настраиваемые)
1. **Точечный источник** (лампочка)
   - Положение в пространстве
   - Интенсивность

2. **Направленный источник** (солнце/луна)
   - Направление лучей
   - Интенсивность

3. **Прожекторный источник** (фонарик)
   - Положение в пространстве
   - Направление конуса
   - Ширина конуса
   - Интенсивность

### Модели освещения
Каждый объект имеет свою модель:
1. **Phong** – классическая модель с бликами
2. **Toon Shading** – ступенчатое затенение (cel-shading)
3. **Дополнительная модель** – любая из презентации (кроме Блинна и Ламберта)

## 🛠 Технические детали
- Учет нормалей полигонов при освещении
- Парсинг объектов из внешних файлов
- Настройка параметров для каждого источника света

## ✅ Критерии выполнения
- [ ] Все три типа источников света реализованы
- [ ] Все три модели освещения работают
- [ ] Сцена содержит минимум 5 объектов с текстурами
- [ ] Нормали корректно учитываются при расчетах
- [ ] Поддержка загрузки из внешних файлов
